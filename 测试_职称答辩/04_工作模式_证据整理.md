# 工作模式 证据整理

## 目的

展示从 Word 材料到结构化工作包的完整闭环：读取材料、整理证据、写入结果并提供下载快照。

## 操作

1. 新建对话时选择 **工作模式**，不要先发送消息再切换。
2. 选择技能 **证据梳理**，模型选 **DeepSeek v4**。
3. 上传 `材料-职称答辩海事案件.docx`。
4. 粘贴下面的输入并发送。

## 输入

```text
请在本轮授权的 Word 材料范围内完成证据整理。

交付一个结构化工作包，至少包含：
1. 按日期排序的事实时间线，每条写明来源段落或证据编号；
2. 待证事实清单，区分已证明、部分证明和未证明；
3. 事实与证据的对应表；
4. 材料内部的矛盾、空白和需要补证的项目；
5. 不要判断最终责任，不要把推测写成事实。

完成后先在回答中说明你实际读取了哪些内容，再保存可下载的工作包。
```

## 预期观察

- 页面会显示运行过程和最终回答，并能打开结构化工作包。
- 生成的文件应能下载；如果是 Excel 或 Word，打开后应有清晰标题、表头、可读的换行和必要的来源列。
- 任务失败时可以继续或重新做，已有内容应保留，不应伪装成已完成。

## 人工复核

抽查时间线中的日期、证据编号和 Word 内容是否一致。结构化工作包通过格式校验不等于事实判断正确。
