# 模型对比

## 目的

用同一输入比较 DeepSeek v4 和 GPT 在海事任务中的可用性，比较重点是事实边界和可复核性，不是字数。

## 操作

1. 新建一条 **聊天模式** 对话，模型菜单选 **DeepSeek v4**，发送下面的问题并保存回答。
2. 新建另一条 **聊天模式** 对话，模型菜单选 **GPT**，发送完全相同的问题。
3. 如果 GPT 不可用，记录“当前配置未提供 GPT”，不要把不可用状态当作模型质量结论。

## 输入

```text
请根据“材料-职称答辩海事案件.docx”回答：

1. 目前能够确认的三项事实；
2. 不能确认但会改变责任分析的三项事实；
3. 下一步最有价值的三份证据；
4. 一句说明为什么不能仅凭清洁提单判断承运人最终责任。

请为每一项标明材料依据或“材料未提供”，不要补写文件中没有的日期、金额和责任结论。
```

## 对比表

| 维度 | 观察问题 |
| --- | --- |
| 事实边界 | 是否只使用 Word 中的事实，明确写出未知信息 |
| 结构 | 是否能快速找到事实、缺口和下一步证据 |
| 引用 | 是否能回到材料或资料库原文 |
| 专业谨慎 | 是否避免把研究意见写成最终责任结论 |
| 可执行性 | 下一步证据是否具体、可取得、与争议点相关 |

## 结论写法

只记录可复核差异，例如“模型 A 把封志状态保留为未知，模型 B 将其误写成完整；因此需要人工纠正”。不要用“更聪明”“更专业”这类无法核对的评价。
