## 从空环境启动

需要 Python 3.12+、uv、Node.js 20.9+、npm。Windows PowerShell 示例：

```powershell
git clone https://github.com/xiaoyangbuchicao1-ship-it/zhouxu.git
cd zhouxu\backend
uv sync --locked --group dev --group media --group perception
Copy-Item .env.example .env
```

在 `backend/.env` 填写接手团队自己的 `DEEPSEEK_API_KEY`，随后启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8010
```

另开终端：

```powershell
cd zhouxu\frontend
npm ci
npm run dev -- --port 4173
```

首次使用 OCR 或语义检索时可能下载模型权重；权重不在仓库中。默认无需旧数据，后端会创建空的本地运行库。

## 当前产品逻辑

前端把用户消息、当轮附件和从资源库选择的资料发给后端。后端先保存原件并解析结构，再根据材料规模和当前问题组织上下文。模型可以决定不调用工具，也可以查询当前案件、个人资源、可选网络搜索或隔离的 Python 工具；程序负责授权、调用预算、超时和输出边界。最终模型结合历史与工具观察生成回答，并通过 SSE 流式返回。

感知层不会把整个资料库无条件塞进上下文。短材料可完整阅读，中长材料使用词法与语义混合召回，并保留新上传材料、用户点名材料和反证的优先级。材料不全时仍须先给出当前可支持的分析和条件结论。

## 可选服务

- Docker Python：在 `backend/` 执行 `act_runtime/docker/build.ps1` 构建隔离代码运行镜像。
- SearXNG：在 `backend/` 执行 `scripts/start-search.ps1`，再把脚本输出的地址设置为 `ZHOUXU_SEARCH_ENDPOINT`。
- 语义检索：默认开启，可用 `ZHOUXU_SEMANTIC_SEARCH=0` 关闭；模型缓存位置由 `ZHOUXU_MODEL_CACHE` 控制。

完整变量表见 [后端说明](../backend/README.md)。

## 私密资料与恢复

公开仓库不含以下内容：

- 用户账户、聊天、附件与个人资源库；
- 真实或合成案件资料、专业书籍与评测集；
- 模型 trace、运行日志、检索索引和模型权重；
- API Key、第三方服务凭证与浏览器登录状态。

这些内容如需交接，使用本地私密交接目录中的校验清单、资料 ZIP 和恢复工具。恢复应在首次启动新环境前进行；工具必须拒绝覆盖接收方已有文件。公开可阅读的资料也不当然拥有再发布授权，需逐项核对来源和许可。

## 验证顺序

工程检查：

```powershell
cd backend
.\.venv\Scripts\python.exe -m pytest tests -q

cd ..\frontend
npm run typecheck
npm run build
```

产品走查至少覆盖：注册或登录 → 日常问候 → 新建聊天 → 上传多份资料或从资源库选择 → 查看流式过程 → 追问 → 追加材料纠正 → 重新打开历史 → 删除聊天。

专业回答需另行检查事实与主张的区分、相反证据、引用定位、时间与金额计算、有限材料下的条件表达，以及新增材料后是否正确修订。HTTP 成功、固定模型测试或文字看起来完整，都不能替代专业验收。
