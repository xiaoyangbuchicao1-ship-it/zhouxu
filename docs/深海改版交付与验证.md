## 设计与实际交付

本版不沿用原版或白昼版外观。首页以连续的货船航拍、银白中文命题和上下分布的行动区形成海事舞台；登录收束为同一场景中的填写区域；进入对话后，影像退出长内容区，留下紧凑全局导航、可展开的会话/项目目录、664px 阅读轴与按需资料面板。

三个参考的实际转译如下。依据是 brief 已核对的可读 Prompt，未声称观看了原案例视频。

| 参考 | 落地位置与机制 | 没有采用 |
| --- | --- | --- |
| Immersive Ocean | 首页完整媒介舞台、上方标题与底部行动；登录共享影像光色；手机独立裁切 | 原品牌、外链视频、核心行动延迟可用 |
| Monolith Hero | 首页目录即时选中、示例与说明联动；旧 WAAPI 取消，最后选择生效；会话请求序号防止旧响应覆盖 | 石门、房地产叙事、声音假按钮、自动轮换 |
| Neo Museum | 不等分工作方式目录与材料对象；资源库文件名优先、选中目录对应真实元信息 | 伪 PDF 原文、假页码、粒子消散、微字 |

页面 `/`、`/login`、`/login?mode=register`、`/app` 与 `#method` 保留。首页问题入口带入真实工作台草稿，不自动发送。资源库仍为应用内视图。

正式资产为 `frontend/public/images/deepsea-cargo.webp`（2400×1672，888752 bytes）。原作 [Aerial photograph of a cargo ship](https://commons.wikimedia.org/wiki/File:Aerial_photograph_of_a_cargo_ship.jpg)，Wilfredor，CC BY-SA 3.0；缩放、去饱和、WebP 转换的衍生影像沿用同许可。完整署名见 `frontend/public/images/LICENSE.md`，页面提供来源链接。不使用案例素材或私人材料。字体继续使用既有本地 MiSans 与许可。

主实现：`frontend/app/tokens.css`、`components/landing-*`、`auth-panel.*`、`conversation-workspace.*`。静态首页保持服务端渲染，章节、草稿、动效和表单为独立 Client Components；没有增加依赖或修改后端协议。`frontend/DESIGN.md` 记录实际系统。

## 预览与运行

本地预览：[http://127.0.0.1:4173](http://127.0.0.1:4173)。首页与登录可直接查看，工作台需要真实登录。源码运行：

```powershell
cd D:\projects\codex\OPC\海事Agent项目\frontend
npm run build
npm run start -- --port 4173
```

应用按既有网关连接 `http://127.0.0.1:8010`；也可使用原有 `ZHOUXU_API_URL` 配置，不改变鉴权或数据合同。后端正常启动方式：

```powershell
cd D:\projects\codex\OPC\海事Agent项目\backend
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8010
```

模型回答还需要原有 `backend/.env` 中的 `DEEPSEEK_API_KEY`。不要将密钥写入源码、聊天或验收文档。

交付截图保存在本机 Codex visualizations 下的 `zhouxu-deepsea` 目录，包含桌面/手机首页、注册登录、长内容、资料列表/详情/选择和失败状态。长内容画面始终标明“合成排版验收 · 非模型回答”，不是实际法律分析成绩。

## 动效：触发、目的、时长与替代

| 触发 | 目的与当前实现 | 中断、键盘与减少动效 |
| --- | --- | --- |
| 本会话第一次首页 | 标题640ms、80ms错开；场景1100ms轻量收束。标题/按钮默认可见且可点 | sessionStorage 避免回访重演；卸载取消；减少动效直接静态 |
| 指针选择首页章节 | 状态立即，材料与说明500ms、8px轻移，解释关联 | 新选择取消旧 WAAPI；键盘/减少动效即时 |
| 指针切换登录模式 | 保留共同字段与表单节点，200ms透明度反馈 | 新操作取消旧动画；键盘/减少动效无动画 |
| 指针首次发问 | 同一输入器260ms位置连续过渡，不重新挂载 | 键盘/减少动效即时；卸载取消 |
| 资料选择 | 实际成功后立即更新勾选与计数，不用动画排队 | 本地新对话即时；已有对话按真实接口结果更新，不伪装成功 |
| 手机目录 | 240ms打开、180ms关闭，说明横向空间关系 | CSS可反向；Escape、焦点约束与归还；减少动效即时 |
| 居中浮层 | 240ms淡入、170ms淡出，中心稳定，无缩放漂移 | 关闭态禁止误触；键盘/减少动效即时；Radix管理焦点 |
| 下拉菜单 | 180ms进入、140ms退出，沿 Radix 触发原点 | Escape、方向键与焦点归还；键盘/减少动效即时 |
| 指针按压 | 120ms轻微0.98缩放，确认接收 | 键盘不动画；减少动效移除缩放；hover只在精确指针启用 |
| 输入、搜索、流式正文 | 即时，不逐字演出，不等待动画 | 原生滚动、选择与焦点；正文不重复入场 |

UI缓动为 `cubic-bezier(.23,1,.32,1)`，品牌揭示为 `cubic-bezier(.16,1,.3,1)`。没有滚动劫持、自定义光标、磁吸按钮、持续视差或循环海景视频。可现场操作路径：首页首次打开→章节连续点击/方向键→登录模式往返→工作台目录及选择资料→Escape返回。

### 响应式与可访问性

生产浏览器覆盖360、390、768、1024、1440px；首页及工作台均无整页横向溢出。正文664px/17px/31.45px行高；手机输入16px，正文16px/1.8。手机宽表格容器348px、内容780px，而整页390px，仅局部滚动。

390×480缩短视口检查时，shell为480px、发送按钮底边约375px，仍可见。已检查VisualViewport响应、安全区域CSS；没有物理手机软键盘或真实浏览器工具栏测试，不能据此宣称所有硬件通过。

已检查Tab、章节方向键/Home/End、Escape、浮层关闭后焦点归还、手机目录焦点约束、删除确认安全初始焦点。中文输入保留 `isComposing` 与229保护、Shift+Enter换行路径；未做真实中文输入法硬件录入验收。减少动效使用系统媒体查询，静态内容与行动保持可用。

对比度计算：主文字/主底16.04:1，辅助文字/主底8.14:1，辅助文字/抬升面6.86:1，白字/主行动4.92:1。图片上的文字使用固定遮罩与安静裁切区，并检查桌面/手机画面；这不是每个图像像素的自动WCAG审计。

### 性能与专业质量

本地生产、1440×900、缓存已热、无CPU/网络降速的单次观察为 LCP约80ms、CLS0。仅说明该本机样本，不能外推真实网络、低端设备或线上分位数；INP未测。LCP<2.5s、INP<200ms、CLS<0.1仍为目标，不写成全面通过。

固定合成材料、接口成功和排版截图不能证明法律答案质量。本次没有专业模型答案质量结论。

## 二十条 UI/UX 原则逐项核对

| 原则 | 当前处理与证据 |
| --- | --- |
| 01 选择个性 | 连续海洋舞台与案卷阅读轴贯穿首页、登录、应用；新探索待用户评价 |
| 02 先层级后色彩 | 深底三层、三档文字明度、字重与组距承担层级；钴蓝只强调主行动与状态 |
| 03 字号不是万能 | 主要正文16–17px、辅助至少14px；通过字重/明度/间距弱化，不缩成微字 |
| 04 弱化竞争元素 | 非当前导航与次行动低强调；主按钮实心，资源库操作不满屏同权重 |
| 05 减少冗余标签 | 文件名优先；状态和时间其次。表单label与需要辨认的详情字段保留 |
| 06 按主次定义按钮 | 删除在目录中低强调，仅确认框升高；发送/提交为主要动作 |
| 07 从充裕留白起步 | 首页大场景；密集操作按任务收紧，不将营销页空白套入聊天 |
| 08 不填满宽屏 | 阅读区664px，表单受控宽度；目录按需展开，无空的常驻第三列 |
| 09 亲疏间距 | label与字段8px、组间更大；Markdown标题上距大于下距，段落与材料分组 |
| 10 非等比缩放 | 手机独立影像裁切、导航图标/抽屉、资料单层列表→详情；不是缩小桌面画布 |
| 11 行长行高 | 桌面约39个中文字符/行、17px/1.85；手机16px/1.8，宽表格局部滚动 |
| 12 基线对齐 | 首页章节标题/说明及文字行使用baseline；图标按钮居中属于可操作目标，并非混排文字基线 |
| 13 实用色阶 | tonal ramps + surface/text/action/state语义tokens；错误与选中有独立角色 |
| 14 可读对比 | 计算文字与表面、按钮对比；深色世界不强行套浅底色示例，状态有足够文字反差 |
| 15 不只靠颜色 | 选中有勾选/文字/aria-pressed；失败有图标/说明；运行状态来自真实事件 |
| 16 强调边框 | 用于输入焦点、选中目录与细线，不为凑规则添加装饰彩色侧条 |
| 17 图片文字稳定对比 | 固定深蓝遮罩、主体与文字错开；图片失败时深底及行动仍成立 |
| 18 适用尺寸 | Lucide维持小尺寸；摄影有明确裁切，产品入口是真组件，不是缩小的假后台截图 |
| 19 克制边框 | 阅读正文无卡片；资料用列表/色阶/留白，只有输入、表格及必要分隔使用细线 |
| 20 空状态 | 空对话直接提问，空库突出上传；无搜索结果给清空动作，空项目前不显示多余筛选壳 |
