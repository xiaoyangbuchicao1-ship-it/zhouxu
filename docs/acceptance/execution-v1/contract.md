# 可执行海事任务：首轮合同

用户：海事专业人员。承诺：智能体读取授权材料，用真实代码处理数据，检查运行结果，交付可下载文件；常识问答不强制执行。

工具接口与执行后端分离，参考本地DeepSeek Harness的fs/shell/sandbox/deliverables约定。当前Windows ACL仅部分写限制，因此本轮使用现有Docker Linux执行世界；不把宿主终端当成隔离沙箱。

首轮边界：每个可信run独立容器，无网络、无宿主挂载、不传用户凭证、非root、只读root、工作区tmpfs限额、CPU/内存/PID/超时/输出限制。工作区由服务端选择，不接受模型选择账户或宿主路径。无runner则失败关闭。业务工具仍用于真实检索和精确金额计算。生成文件显式present后复制到不可变内容快照，鉴权下载；不可由模型拼宿主URL。停止/超时须终止执行子进程。此环境不是抵御所有内核漏洞的虚拟机边界。

必须验证：真实write/read/edit/bash→运行Python→生成xlsx/docx→present→本账户下载；不同run隔离；路径越界/符号链接/覆盖冲突/缺失文件/超大文件拒绝；无网络和宿主挂载；超时停止；模型真实修复脚本错误；未授权下载404/401；持久交付在容器销毁后可下载；旧海事工具和业务不回归。专业事实忠实与法律正确性另验，不由文件存在证明。

尚待用户选择首轮专业场景，先实现共同执行与交付机制。没有授权自动发送、安装全局插件、提交推送或修改原语料。

用户补充确认：前端明确区分聊天与工作。默认聊天，不提供五个执行工具，也不得创建执行环境；工作才按本轮授权开放隔离执行。task_mode在服务端校验并随run保存，steer不能升级/降级原run，重试保留原run模式；页面切换只影响下一次请求。必须测试默认、非法值、隐藏工具直呼拒绝、运行中切换不改权限、工作真实生成文件。
