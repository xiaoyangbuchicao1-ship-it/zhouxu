## 本次真实返工

1. 仅核对技能当前可见性，会让公开 v2 的读者取得原本私密 v1。已按历史版本单独限制；作者可查历史，其他用户只能查可见当前版本。
2. 在线命中依赖本地索引补原文，会在本地缺少该文时 404。已保存内容寻址快照，同一编号的新旧正文仍分别可核对。
3. 普通提交解析技能，steer/legacy 直接透传 facts，会使任务切换方法未生效或伪造正文混入。已统一所有入口解析，前端重做保留技能与案件选择。
4. 真实模型复制长 URL 时改写编号、编造域名；仅能生成正文的冒烟不足以验收。改为短引用标记，由后端查快照生成链接，并校验真实 HTTP 解析。编码路径也须规范化后校验。
5. 全量 Windows 回归发现 `with sqlite3.connect(...)` 不会关闭连接，临时库删除被文件锁阻止。已拆开事务与连接生命周期，显式关闭；保留原失败运行和最终通过证据。
6. 从工作区根调用 Vite 子目录构建，Tailwind 的工作目录约定不成立。正式验证脚本在前端目录执行原生命令，保留原退出码；没有删样式或放松构建标准。

专业限制：引用可打开不等于论证相关、全文已读或法律结论正确。模型可能遗漏、误解、过度检索或生成不合适的分析，必须结合原始材料与海事专业评审继续验收。样例是系统验收演示数据，不是真实客户案件，也不是准确率基准。八项完成不代表统计稳定性、提示注入防御或生产安全全面通过。
