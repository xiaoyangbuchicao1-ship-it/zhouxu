# Skill 离线评测合同

本目录保存 Skill 的固定验收输入和期望行为。它不属于生产运行时，生产代码不得读取本目录中的题目、期望答案、评分标准或历史结果。

每个 Skill 评测文件使用以下结构：

```text
skill_name
evals[]
  id
  prompt
  expected_output
  expectations[]
```

`expectations` 应覆盖真实工作闭环，而不只检查最终文字：

- 是否在需要时读取正确的 Skill；
- 是否调用了允许的工具，并遵守 `required` / `never` / `optional` 检索边界；
- 关键结论是否绑定实际证据和可读来源；
- 工具无命中、部分结果、故障或版本不一致时，是否如实交付缺口；
- 是否避免把 Skill 说明、模型推断或内部索引当作事实证据。

题目和 gold 一旦进入基准，不应为了让某个模型通过而修改。新增或修改 Skill 时，先更新对应评测文件，再使用真实工具轨迹和来源卡验收；评测代码、临时日志和历史报告不放入生产模块。
