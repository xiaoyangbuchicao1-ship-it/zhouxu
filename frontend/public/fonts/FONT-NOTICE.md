# 舟序落地页字体

本目录是正式页面的自托管字体资源，不依赖 `design-previews/` 或临时目录。

- `instrument-serif-regular.ttf` 与 `instrument-serif-italic.ttf`：Instrument Serif 400，分别为正体、真实斜体。来自 Google Fonts CSS API 指向的 fonts.gstatic.com 官方字体文件。保留原模板的英文展示语言。许可见 `Instrument-Serif-OFL.txt`。
- `noto-serif-sc.woff2`：Noto Serif SC 完整可变字体，中文标题采用 500 字重。由本机已安装的 Noto Serif SC 字体以 FontTools 无损转换为 WOFF2，未裁切字集。许可见 `Noto-Serif-SC-OFL.txt`。
- `noto-sans-sc.woff2`：Noto Sans SC 完整可变字体，用于正文与界面。由本机已安装的 Noto Sans SC 字体以 FontTools 无损转换为 WOFF2，未裁切字集。许可见 `Noto-Sans-SC-OFL.txt`。

以上字体均遵循 SIL Open Font License 1.1。许可原文与版权声明随字体保留。Noto 中文字体包含完整字集，和前期只覆盖样稿文字的子集不同。

字体官网与源码：

- https://github.com/Instrument/instrument-serif
- https://github.com/notofonts/noto-cjk
- https://github.com/google/fonts/tree/main/ofl/notoserifsc
- https://github.com/google/fonts/tree/main/ofl/notosanssc

中文展示的商业字体候选“方正清刻本悦宋”未被下载或嵌入。本版本采用用户已认可的开放字体备选。
