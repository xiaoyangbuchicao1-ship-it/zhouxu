# 工作台 / Operate

Audience: 处理海事争议的专业使用者。
Job: 在可持续的对话中梳理问题、添加材料、选择个人资料并检查分析依据。
Action: 新建或继续对话，附件随轮次发送，项目只作分组。
Direction: 用户已批准的研究桌面结构；不是仪表盘。左侧 248px 历史和项目，中央空态欢迎与输入区，右侧 340px 资料面板默认关闭。移动端使用独立导航和资料抽屉。
Memorable moment: 第一轮提问后欢迎区退场，输入区连贯移至底部；资料面板双向滑动，菜单从触发点展开，选择背景连续移动。
Constraints: 保留已确认落地页及登录视觉和原图片视频；后端不改，不参考旧前端。以真实完成事件判断保存；资料选择不冒充引用；不给不存在的能力做入口。正常模式动态交互完整，系统减少动态效果时减少位移。
Approval: 本次用户“可以，但是不要减少动态交互丝滑效果”，随后“先建立 git tag 前端v1.1 再根据方案进行优化”。现有世界精确扩展，无新方向随机选择或概念图审批步骤。
Open: 无待决视觉方向；专业内容质量不由固定模型 QA 证明。
