# 舟序 Zhouxu

## Platform

web

舟序面向处理海事争议、仲裁及相关研究材料的专业使用者。核心旅程是登录、提出问题、添加材料或选择个人资料、阅读有依据的分析，并回到历史对话继续研究。

## 本次已确认范围

- 落地页沿用开源前端二创，现有图片、视频及已认可的登录注册视觉保持不变。
- 工作台采用对话优先的研究桌面；左侧项目与历史，中央问答，右侧资料按需展开。
- 通过新后端模块化单体的认证、Harness 运行和后续工作区接口完成真实研究旅程；前端不绕过账户权限读取数据。
- 七项面向用户的海事工作规范由服务端解析并固定到运行快照；模型结合材料读取、真实法规/案例检索和按需精确计算工具执行。技能以指令包运行，不执行用户上传代码，尚未通过专业法律质量验收。
- 技能工坊支持私人编写、改编、版本保存与向平台注册用户分享。案件支持明确邀请成员、角色、任务责任人、日期、证据笔记、文书版本、人工复核和操作留痕；可将案件记录交给智能体，并把回答回存草稿。
- 提供 Markdown 草稿和计算明细导出；不承诺期限提醒、Word 协同编辑、外部送达、律师资质认证或开放代码插件市场。专业结论需核对原文与适用条件。

## 真实状态与边界

会话附件与账户资料库分离；选择资料只使其可供本次对话使用，不代表回答已引用。已发送附件不能在前端删除。项目删除只解除分组，不删除对话。连接中断不代表后台停止，也不能显示保存成功；只有服务完成事件证明本轮已保存。

## 品牌与交互约定

保留用户提供的帆形标识与 Zhouxu 字标，衔接已认可页面的设计语言。中文清晰可读，英文适度点缀。正常模式保留连贯、可打断的动态交互，同时尊重系统减少动态效果偏好。移动端重新组织布局，不缩小桌面页面。
